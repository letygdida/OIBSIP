# NEXORA AI — Landing Page

## 📌 OASIS INFOBYTE Internship

**Track:** Web Development & Designing  
**Level:** Level 1  
**Task:** Task 1 — Landing Page

## 📖 About the Project

Nexora AI is a modern responsive landing page designed for a fictional artificial intelligence technology startup.

The website presents the company's AI solutions, features, mission, and contact information through a clean and professional interface.

## 🚀 Features

- Sticky navigation bar
- Hero section with call-to-action buttons
- Features section
- About section
- Call-to-action section
- Contact and footer section
- Smooth scrolling navigation
- Responsive mobile layout
- CSS Flexbox and Grid
- Consistent modern visual design

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📱 Responsive Design

The website is designed to work across:

- Desktop computers
- Laptops
- Tablets
- Mobile devices

Responsive CSS media queries are used to adapt the layout to smaller screen sizes.

## ▶️ How to Run

1. Download or clone the repository.
2. Open the `WebDev-L1-LandingPage` folder.
3. Double-click `index.html`.
4. The website will open in your web browser.
